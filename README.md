# Miniaventuras

Aplicación educativa infantil en etapa inicial, construida con React, JavaScript y CSS. Hace parte de la Fundación Universitaria del Área Andina y de la Cátedra Pablo Oliveros Marmolejo.

## Ejecutar localmente

```sh
npm install
npm run dev
```

## Estructura actual

- `src/App.jsx`: composición de la portada y datos del equipo.
- `src/components/`: componentes reutilizables, cada uno en su propia carpeta con su CSS.
- `src/assets/`: recursos visuales, incluido el logo institucional.
- `Guias/`: norte de diseño, contenido y alcance funcional del proyecto.

La portada presenta la iniciativa, la cátedra y el equipo. La navegación por asignaturas y actividades corresponde a fases posteriores de las guías.

## Reglas para continuar

- Mantener JavaScript y CSS; no agregar TypeScript.
- Crear los nuevos componentes en módulos independientes, junto a su CSS.
- Mantener el contenido infantil en español, accesible y con controles amplios.
- Seguir el registro de asignaturas y las plantillas definidas en `Guias/` al implementar las siguientes fases.
